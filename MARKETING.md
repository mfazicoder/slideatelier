# slideAtelier — private beta marketing notes

## What it is, in one line

**slideAtelier turns a brief into a consulting-quality slide deck — native
PowerPoint shapes, native typography, ready to edit.**

## What's different

Most "AI deck" tools generate a JPEG and call it a slide. slideAtelier
emits **native primitives**: every chart, matrix, funnel, and pyramid is
real PowerPoint geometry you can grab a handle on and move. Squares stay
squares. Charts stay charts. The deck is yours to edit, not a screenshot
to redo.

## The three-stage workflow

1. **Storyboard** — Claude reads your brief and proposes the narrative
   arc: title slide, problem, evidence, recommendation, next steps. Edit
   the structure before the LLM touches the body.
2. **Wireframe** — every slide gets a layout, body content, and a chosen
   visual primitive (one of 14 native shapes — funnel / pyramid / Venn /
   timeline / cycle / quadrant / value chain / hex grid / org chart …).
   Drag, resize, rewrite anything.
3. **Hi-fi** — render to native `.pptx` for handoff, or publish a
   sharable Web Deck (HTML + SVG, all native primitives — no canvas, no
   raster).

## Who it's for

- **Strategy + management consultants** who write 30-slide decks weekly.
- **Founders** doing fundraise / board / customer pitches.
- **Product / marketing leads** who do quarterly business reviews and
  hate fighting PowerPoint shape menus.

## What's in the private beta

- Email + password signup, invite-only.
- Three-stage workflow end-to-end.
- 14 native asset shapes × 4 themes = 56 brand-coherent visual primitives.
- Native `.pptx` export (handoff to clients / partners who live in
  PowerPoint).
- Hosted Web Deck — a `https://<host>/web/<slug>` URL with keyboard nav,
  fullscreen, and a presenter mode that overlays speaker notes.
- Selective text stripping when you import a chart from your library —
  outer slide chrome (titles, footers) stripped, inline annotations kept.
- Per-block typography overrides (font, size, color, bold, italic,
  alignment) on every text element.
- Multi-tenant — each user's decks live in a private namespace.

## What's coming next (queued sprints, abridged)

- **Brand Kit** — onboarding wizard captures your logo, colors, type
  pair, audience tone → emits a custom theme. One-click rebrand across
  every deck.
- **Atelier Copilot** — sticky right-rail chat anchored to current
  selection. "Ask AI" issues *scoped* edits, not full regenerations.
- **Outline Plan Mode** — see + edit the slide-by-slide plan before
  generating. Saves Opus tokens and eliminates wholesale-regen weakness.
- **Named Version Cards** — every AI turn becomes a labelled card on a
  branching history rail. Restoring an old card forks rather than
  overwrites.
- **Storyboard Whiteboard** — infinite mindmap-style canvas for the
  pre-storyboard ideation phase.
- **Deck Variants + Localisation** — one canonical deck → N audience
  variants × M languages.
- **Slide Analytics** — viewer-side telemetry on Web Decks (slide
  retention, dwell, CTA CTR).
- **Deck Audit (linter)** — flags >40-word slides, off-theme colors,
  missing speaker notes, accessibility gaps.
