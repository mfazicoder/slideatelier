API keys

An API key lets your AI coding tool (Cursor, Windsurf, Claude Code, Cline, Codex, Antigravity — via the Hatchik MCP) talk to your Hatchik project from chat: deploy, check status, redeploy, etc. Paste the key into the MCP config snippet on hatchik.com/install in place of YOUR_HATCHIK_API_KEY.

Heads-up: a new key’s plaintext is shown only once, the moment you create it. Copy it then — we only keep a one-way hash after that. Lost the key? Revoke and reissue, no harm done.
