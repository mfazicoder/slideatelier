{# ----------------------------------------------------------------------------- _font_picker.html — reusable Jinja partial for choosing a font. Required context vars: picker_id — unique DOM id prefix (e.g. "heading", "body") field_name — form field name to submit (e.g. "heading_font") initial_value — currently-selected font family string The picker writes the selected font name into a hidden so existing form-handling code (e.g. /design-system/save) keeps working. The first time it appears on a page, it injects a single into that batch-loads ~30 popular Google fonts. The remaining curated fonts are lazy-loaded individually when the user previews them. System fonts come from window.queryLocalFonts() (Chromium 103+); user fonts come from /api/fonts/user and are loaded via a per-font @font-face declaration. ----------------------------------------------------------------------------- #}
